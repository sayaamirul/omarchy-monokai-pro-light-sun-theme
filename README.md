# Omarchy Monokai Pro Light Sun Theme

A [Monokai Pro](https://monokai.pro/) **Light (Filter: Sun)**-inspired theme for [Omarchy](https://omarchy.org/).

Color palette referenced from community ports of Monokai Pro Light Sun
([iTerm2-Color-Schemes](https://github.com/mbadolato/iTerm2-Color-Schemes),
[monokai-pro/zed CE](https://github.com/monokai-pro/zed)). Monokai Pro is a paid
theme by Sublime HQ / monokai.pro — this is a fan-made color approximation.

## Install

```bash
omarchy theme install https://github.com/sayaamirul/omarchy-monokai-pro-light-sun-theme.git
```

Or manually:

```bash
git clone https://github.com/sayaamirul/omarchy-monokai-pro-light-sun-theme.git ~/.config/omarchy/themes/monokai-pro-light-sun
omarchy theme set monokai-pro-light-sun
```

## Includes

- Full color palette (`colors.toml`) matching Monokai Pro Light Filter Sun
  - Background `#f8efe7` · Foreground `#2c232e`
  - Red `#ce4770` · Orange `#d4572b` · Yellow `#b16803` · Green `#218871` · Blue `#2473b6` · Purple `#6851a2`
- Neovim colorscheme config (loctvl842/monokai-pro.nvim, light filter)
- Chromium tint and Yaru icons
- Wallpapers (Dragon Ball Z)
